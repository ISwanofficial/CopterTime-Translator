# История изменений

## 0.4.0

### Добавлено

- модульная архитектура;
- база SQLite;
- память переводов;
- редактор терминов;
- брендовые словари;
- диагностика документа;
- проверка оставшегося английского текста;
- импорт старого glossary.csv;
- документация проекта.

### Изменено

- проект переименован в CopterTime Docs;
- DOCX закреплён как основной рабочий формат;
- перевод выполняется по коротким фрагментам с ограничением длины.

### Ограничения

- перевод текста внутри изображений отсутствует;
- сложные элементы Word могут требовать ручной проверки.
