# CopterTime Docs v0.4

Внутренний инструмент CopterTime для перевода технических DOCX-документов с сохранением структуры, фирменной терминологии и памятью переводов.

## Что появилось в v0.4

- SQLite вместо CSV как основное хранилище.
- Память переводов: одинаковые фрагменты не переводятся повторно.
- Встроенный редактор терминов.
- Брендовые словари: General, QYSEA, DJI, BETAFPV, FIMI, MJX, ToolkitRC.
- Диагностика DOCX до перевода.
- Контроль оставшегося английского текста после перевода.
- Журнал работы и понятные сообщения об ошибках.
- Автоматический импорт старого `glossary.csv`, если он лежит рядом с программой.

## Установка

```bat
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

## Быстрый запуск в Windows

Запустите `run.bat`.

## Данные

База создаётся автоматически:

```text
data/coptertime_docs.db
```

Её можно копировать для резервного сохранения словаря и памяти переводов.

## Ограничения v0.4

- Основной рабочий формат — DOCX.
- Текст внутри изображений не переводится.
- Сложные текстовые поля Word, SmartArt и часть надписей в фигурах могут потребовать ручной проверки.
- PDF рекомендуется сначала конвертировать в DOCX.
