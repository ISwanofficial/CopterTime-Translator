# CopterTime Translator

Перевод технической документации EN → RU с сохранением структуры DOCX.

## v0.3

- перевод DOCX и текстовых PDF;
- сохранение изображений и таблиц в DOCX;
- расширенный технический словарь;
- кэш переводов;
- очистка частых машинных формулировок;
- экспорт в PDF через Word или LibreOffice;
- кнопка открытия словаря.

## Запуск

1. Запустите `install_and_run.bat`.
2. Выберите DOCX.
3. Нажмите **ПЕРЕВЕСТИ**.
