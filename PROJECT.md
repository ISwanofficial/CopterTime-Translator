# CopterTime Docs

## Назначение

CopterTime Docs — внутренний инструмент для подготовки русскоязычной технической документации CopterTime.

## Главная цель

Сократить ручную работу при переводе и проверке инструкций, сохраняя структуру документа и единообразную терминологию.

## Принцип продукта

> Один клик вместо часа ручной работы.

Новая функция принимается в проект, только если она:

1. экономит время;
2. снижает количество ошибок;
3. улучшает качество документа.

## Границы v1.0

- стабильный перевод DOCX;
- словари по брендам;
- память переводов;
- диагностика и проверка качества;
- удобный внутренний интерфейс;
- безопасное локальное хранение данных.

## Не входит в v1.0

- публичный облачный сервис;
- многопользовательские роли;
- интеграции с маркетплейсами;
- сложное OCR;
- автоматическое редактирование текста внутри изображений.
