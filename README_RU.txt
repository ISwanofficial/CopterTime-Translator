CopterTime Translator v0.2.1

Эта версия:
- не использует OpenAI API;
- не устанавливает PyTorch;
- требует интернет во время перевода;
- переводит через Google Translate без API-ключа;
- сохраняет структуру DOCX настолько, насколько позволяет python-docx;
- создаёт PDF через установленный Word или LibreOffice.

Установка:
1. Распакуйте файлы в C:\CT
2. Удалите старую папку .venv, если она есть.
3. Запустите install_and_run.bat
4. После установки выберите DOCX и нажмите ПЕРЕВЕСТИ.

Для сложных PDF сначала преобразуйте PDF в DOCX.

Исправлено в v0.2.1:
- длинные абзацы автоматически делятся на безопасные части;
- устранена ошибка length must be between 0 and 5000 characters;
